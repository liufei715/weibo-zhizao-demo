# 蔚博智造个人展示站

在线预览：https://liufei715.github.io/weibo-zhizao-demo/

本仓库用于个人项目页面展示，由 liufei715 个人 GitHub 账号维护，独立于公司部署平台。

仅发布网页运行所需的 HTML、CSS、JavaScript 和已授权预览图片。网页前端文件可被公开查看与下载；开发文档、测试和未公开源码不在本仓库发布。

不包含原始工程 PDF、Gerber、结构源文件、产品资料目录、账号密钥或个人操作记录。

## 更新与发布

GitHub Pages 从 main 分支根目录发布，保留 .nojekyll。更新先在分支核对，再合并 main；历史提交可用于恢复页面版本。

本仓库面向页面与交互体验展示，真实 AI、微信、短信或支付服务需另行接入和验证。
